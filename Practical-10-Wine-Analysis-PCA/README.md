\# Practical 10: Wine Dataset Analysis and Principal Component Analysis (PCA)



\## Aim

To perform exploratory data analysis and visualization on the Wine dataset, apply feature scaling, and use Principal Component Analysis (PCA) to reduce dimensionality and visualize different wine classes.



\## Dataset

\- \*\*Dataset:\*\* Wine Dataset

\- \*\*Source:\*\* Scikit-learn (`sklearn.datasets.load\_wine`)

\- \*\*Total Records:\*\* 178

\- \*\*Independent Features:\*\* 13

\- \*\*Target Classes:\*\* 3



\### Wine Classes

\- Class 0

\- Class 1

\- Class 2



\### Features

The dataset contains 13 chemical measurements, including:

\- Alcohol

\- Malic Acid

\- Ash

\- Magnesium

\- Total Phenols

\- Flavanoids

\- Color Intensity

\- Proline



\## Technologies and Libraries

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Scikit-learn



\## Practical Tasks



1\. Load the Wine dataset and display basic statistics using `head()` and `describe()`.

2\. Analyze the dataset using class labels.

3\. Create boxplots to compare feature distributions across wine classes.

4\. Create scatterplots using two selected variables.

5\. Calculate and visualize the covariance matrix.

6\. Apply feature scaling using StandardScaler.

7\. Apply Principal Component Analysis (PCA).

8\. Reduce the original 13 features to 2 principal components.

9\. Visualize the wine classes in a two-dimensional PCA plot.



\## Concepts Covered



\- Exploratory Data Analysis (EDA)

\- Data Visualization

\- Boxplots and Scatterplots

\- Covariance Matrix

\- Feature Scaling

\- Standardization

\- Dimensionality Reduction

\- Principal Component Analysis (PCA)



\## Conclusion



The Wine dataset was analyzed using Pandas and Matplotlib. Different visualizations were used to understand feature distributions and relationships between variables.



Feature scaling was performed before applying PCA. Principal Component Analysis was used to reduce the dimensionality of the dataset from 13 original features to 2 principal components, making it possible to visualize the wine classes in two dimensions.
